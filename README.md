# 21 Days of DSA with JavaScript

This repository contains my 21-day practice journey focused on improving problem-solving skills and strengthening DSA fundamentals using JavaScript.

## What is this?

A hands-on practice challenge where I solve different programming and DSA problems using JavaScript.

The main goal is to improve logical thinking, problem-solving ability, and understanding of common algorithms and data structures.

## What I Will Practice

* Number and mathematical problems
* Conditional logic
* Patterns and loops
* Strings
* Arrays
* Sorting algorithms
* Searching algorithms
* Recursion
* Trees
* Binary Search Trees

## How I Practice

For each problem, I focus on:

1. Understanding the problem
2. Breaking it into smaller steps
3. Developing the logic
4. Implementing the solution in JavaScript
5. Testing the solution with different inputs
6. Improving the solution when possible
